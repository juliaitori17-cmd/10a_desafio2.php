# 🗄️ Backup e Restauração de Banco de Dados MySQL

## 📌 Sobre o projeto

Este projeto foi desenvolvido como uma atividade prática sobre **backup e restauração de bancos de dados utilizando o MySQL**.

Durante a atividade, foram realizados procedimentos para criar cópias de segurança do banco de dados e restaurar informações quando necessário.

## 🎯 Objetivo

O objetivo é compreender como realizar:

* Criação de backup completo do banco de dados;
* Backup de uma tabela específica;
* Restauração de um banco de dados;
* Restauração de uma tabela;
* Verificação dos dados após a restauração.

## 🛠️ Tecnologias utilizadas

* **MySQL**
* **MySQL Workbench / Terminal**
* **SQL**

## 🗃️ Banco de dados

O banco de dados utilizado no projeto foi:

```text
sistema_eleitoral
```

Também foi realizado um backup específico da tabela:

```text
eleitor
```

## 💾 Backups realizados

Foram criados dois tipos de backup:

### Backup completo

Foi realizada uma cópia de segurança contendo a estrutura e os dados do banco `sistema_eleitoral`.

### Backup da tabela

Também foi criado um backup direcionado à tabela `eleitor`, permitindo recuperar somente essa parte do banco quando necessário.

## 🔄 Restauração

A restauração permite recuperar os dados e a estrutura do banco de dados a partir dos arquivos de backup.

Esse procedimento é importante para evitar a perda definitiva de informações em situações como erros, exclusões acidentais ou problemas no banco de dados.

## 🔐 Importância do backup

Manter backups atualizados é uma prática importante para garantir a segurança das informações.

Com uma cópia de segurança disponível, é possível recuperar os dados quando ocorrer algum problema no banco de dados.

## 📚 Conclusão

A atividade permitiu compreender, na prática, como funcionam os processos de **backup e restauração no MySQL**.

Também foi possível observar a importância de manter cópias de segurança para preservar os dados e facilitar sua recuperação quando necessário.
